8-Point Security Checklist

Each uploaded document is assessed against the following security criteria:

  1. 1
    Complete Metadata Validation
    Verifies document properties including author, producer, and creation tool.
  2. 2
    Creation vs Modification Date Consistency
    Checks for suspicious timestamp discrepancies.
  3. 3
    Incremental Update Detection
    Identifies post-creation modifications indicating tampering.
  4. 4
    Trusted Software Whitelist Verification
    Validates the document was produced by recognised software.
  5. 5
    JavaScript & Executable Code Detection
    Scans for embedded scripts or executable content.
  6. 6
    Encryption Analysis
    Evaluates encryption status and security configuration.
  7. 7
    Embedded Files Detection
    Identifies hidden or embedded files with potential payloads.
  8. 8
    File Structure Integrity (±10% threshold)
    Validates internal PDF structure against expected standards.
